# 用精确日复利与日末投入作为唯一推算口径

**Status**: accepted · 2026-10-30

用户输入的是一年 365 天的假设年化收益率，但投入是按天发生的，因此必须明确"年化如何折算到每天"以及"当天投入从哪天开始计息"。我们决定：日利率 `r = (1+R)^(1/365) − 1`（精确日复利，而非 `R/365`），每天先计息、再加当天投入，即 `B(次日) = B(当日)×(1+r) + 当日投入`；起始日余额为本金加当日记录，起始日本身不计息；未来的计划日投从明天开始计入。这样曲线在数学上精确对齐用户输入的年化收益率，且符合"当天投入次日产生收益"的定投直觉。

市值核对被视为当日结束后的真实市值，会覆盖当日推算值；同日若有投入记录，记录仍计入累计投入但不重复加进余额。闰年按真实日历日模拟，所以一个日历年可能略多于年化收益率。反推模式以今日推算余额为本金，用闭式解求每日投入，周/月值分别按 7 天与 365/12 天近似。所有预测在 100 年（36,525 天）处截断，超出即判定"无法达成"。

**Consequences**: 今日的计划日投不计入预测，除非用户当天有记录；删除最新一次市值核对后，上一次核对自动成为权威起点；历史上已发生的记录不会因修改年化收益率而改变，但推算余额会按新收益率重算。
