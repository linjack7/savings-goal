# 财务自由本金采用永续保本与实际月收益率

**Status**: accepted · 2026-10-30

用户想知道"每年花多少钱，需要多少本金才能只靠增长覆盖支出"。我们决定按**永续保本**计算：支出每月末取出当年年支出的 1/12，支出每年按通胀率增长，本金按购买力保持不变。设年化收益率 `R`、通胀率 `i`，实际月增长率 `g = ((1+R)/(1+i))^(1/12)`，所需本金 `P = S / (12 × (g − 1))`；`R ≤ i` 时无法覆盖。年化收益率直接取目标设置里的值，保持全站同一假设。

被否的方案：**4% 法则**（`P = S / 4%`）简单，但允许本金波动甚至耗尽，不能保证永续；**固定年限花完**需要额外的年限假设，且必然耗尽本金。用户的原话是"增长完全覆盖支出"，语义上要求本金不减少，因此选择永续保本。

**Consequences**: 结果比"年末取出、`P = S/R`"的简化公式更保守（无通胀时约高 3.6%，有通胀时高得更多）；输入按今天购买力口径，实际结果依赖收益率假设且会有波动；不含税费与手续费。支出按月末取出，与每日记录的攒钱模型分开计算，不混用日利率。
